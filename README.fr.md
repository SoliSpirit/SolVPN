## 🚀 Comment se connecter

1. Ouvrez un client compatible avec V2Ray. Nous recommandons V2Box.
2. Rendez-vous dans la rubrique « Abonnements ».
3. Copiez l’un des liens d’abonnement ci-dessus et collez-le dans cette rubrique.
4. Appuyez sur « Actualiser » pour charger la liste des serveurs.
5. Choisissez un serveur et connectez-vous.

## ❓ Questions fréquentes

**Ces configurations sont-elles gratuites ?**

Oui, toutes les configurations de la liste sont gratuites.

**Quelles applications acceptent ces abonnements ?**

Vous pouvez les utiliser avec V2Box, v2rayNG et Shadowrocket.

**Pourquoi certains serveurs sont-ils lents ?**

Le débit dépend de la localisation du serveur et de sa charge.
