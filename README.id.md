## ✨ Fitur

- ✔️ Konfigurasi gratis dengan fitur yang sebanding dengan layanan berbayar
- ✔️ Dukungan untuk berbagai protokol: VLESS, VMess, Shadowsocks, dan Trojan
- ✔️ Server yang dioptimalkan untuk koneksi berkecepatan tinggi
- ✔️ Daftar server yang diperbarui secara berkala
- ✔️ Impor yang mudah di V2Box, v2rayNG, dan Shadowrocket
- ✔️ Penambahan langganan dengan satu ketukan

---

## 🚀 Cara menggunakan

1. Buka aplikasi yang kompatibel dengan V2Ray. Kami merekomendasikan V2Box.
2. Buka menu langganan.
3. Salin salah satu tautan langganan di atas, lalu tempelkan di kolom alamat langganan.
4. Ketuk Perbarui atau Muat Ulang untuk memuat daftar server.
5. Pilih server, lalu hubungkan.

---

## ❓ Pertanyaan umum

**Apakah konfigurasi ini gratis?**

Ya, semua konfigurasi dalam daftar ini gratis.

**Aplikasi apa saja yang mendukung langganan ini?**

Anda dapat menggunakannya dengan V2Box, v2rayNG, dan Shadowrocket.

**Mengapa koneksi ke beberapa server terasa lambat?**

Kecepatan koneksi bergantung pada lokasi server dan beban yang ditanganinya.

---

## ⚠️ Catatan penggunaan

- Konfigurasi ini dikumpulkan dari sumber publik.
- Kualitas koneksi dapat berbeda-beda pada setiap server.
- Gunakan layanan ini secara bertanggung jawab.
