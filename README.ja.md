## ✨ 主な特長

- ✔️ 有料サービスのような機能を備えた無料設定
- ✔️ VLESS、VMess、Shadowsocks、Trojan の各プロトコルに対応
- ✔️ 高速接続向けに最適化されたサーバー
- ✔️ サーバーリストを定期的に更新
- ✔️ V2Box、v2rayNG、Shadowrocket に簡単にインポート可能
- ✔️ ワンタップでサブスクリプションを追加可能

---

## 🚀 接続方法

1. V2Ray 対応のアプリを開きます。推奨アプリは V2Box です。
2. サブスクリプションの画面を開きます。
3. 上記のリンクから一つをコピーし、サブスクリプションの URL 欄に貼り付けます。
4. 「更新」をタップしてサーバーリストを読み込みます。
5. サーバーを選んで接続します。

## ❓ よくある質問

**設定は無料で使えますか？**

はい。このリストの設定はすべて無料です。

**どのアプリで使えますか？**

V2Box、v2rayNG、Shadowrocket で利用できます。

**接続が遅いサーバーがあるのはなぜですか？**

サーバーの設置場所や混雑状況によって速度が変わるためです。
