## ✨ 주요 기능

- ✔️ 유료 서비스와 비슷한 기능을 제공하는 무료 구성
- ✔️ VLESS, VMess, Shadowsocks, Trojan 등 여러 프로토콜 지원
- ✔️ 고속 연결에 최적화된 서버
- ✔️ 정기적인 서버 목록 업데이트
- ✔️ V2Box, v2rayNG, Shadowrocket에서 손쉽게 가져오기
- ✔️ 한 번의 터치로 구독 추가

---

## 🚀 연결 방법

1. V2Ray 호환 앱을 엽니다. V2Box를 추천합니다.
2. 구독 메뉴로 이동합니다.
3. 위의 구독 링크 중 하나를 복사해 구독 주소 입력란에 붙여넣습니다.
4. 새로 고침을 눌러 서버 목록을 불러옵니다.
5. 서버를 선택한 후 연결합니다.

## ❓ 자주 묻는 질문

**무료로 사용할 수 있나요?**

네, 목록에 있는 구성은 모두 무료입니다.

**어떤 앱에서 사용할 수 있나요?**

V2Box, v2rayNG, Shadowrocket에서 사용할 수 있습니다.

**일부 서버의 연결 속도가 느린 이유는 무엇인가요?**

서버가 있는 지역과 서버 부하에 따라 속도가 달라집니다.
