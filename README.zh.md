## ✨ 功能特点

- ✔️ 免费配置，提供类似付费服务的功能
- ✔️ 支持多种协议：VLESS、VMess、Shadowsocks 和 Trojan
- ✔️ 服务器针对高速连接进行了优化
- ✔️ 定期更新服务器列表
- ✔️ 可轻松导入 V2Box、v2rayNG 和 Shadowrocket
- ✔️ 支持一键添加订阅

---

## 🚀 使用方法

1. 打开兼容 V2Ray 的客户端，推荐使用 V2Box。
2. 进入「订阅」页面。
3. 复制上方任意一个订阅链接，并将其粘贴到客户端。
4. 点击「更新」或「刷新」，获取服务器列表。
5. 选择一个服务器并连接。

## ❓ 常见问题

**这些配置免费吗？**

是的，列表中的所有配置均免费。

**哪些应用支持这些订阅？**

可以使用 V2Box、v2rayNG 或 Shadowrocket。

**为什么有些服务器连接速度较慢？**

连接速度受服务器所在地和当前负载的影响。
